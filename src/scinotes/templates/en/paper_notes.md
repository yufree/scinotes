# Paper notes

One section per paper, written by `paper_ingest`. Section format:

```
## <citation_key> — <title>
- **Authors**: ...
- **Year/Venue**: ...
- **DOI**: ...
- **Tags**: #tag1 #tag2

### Summary
...

### BibTeX
```bibtex
@article{citation_key, ...}
```
```

Manually-written entries are welcome — follow the same shape. Citation keys use `<firstauthor><year><firstword>` (e.g. `smith2024spectroscopy`).
