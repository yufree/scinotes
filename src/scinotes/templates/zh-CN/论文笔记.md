# 论文笔记

每篇论文一节,由 `paper_ingest` 工具自动追加。条目格式:

```
## <citation_key> — <title>
- **作者**: ...
- **年份/期刊**: ...
- **DOI**: ...
- **标签**: #tag1 #tag2

### 摘要
...

### BibTeX
```bibtex
@article{citation_key, ...}
```
```

手工添加请遵守同一格式,citation key 用 `<firstauthor><year><firstword>` 风格(如 `smith2024spectroscopy`)。
